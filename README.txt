SaiSip PWA

Files are ready for static HTTPS hosting.

Important iPhone note:
- Install from Safari using Add to Home Screen.
- Offline use and local tracking work through the service worker/localStorage.
- iOS web push requires the installed PWA, user permission, HTTPS, and a push service/server to deliver notifications while the app is closed.
- The included UI/settings and service worker are push-ready, but truly scheduled background reminders cannot be guaranteed by browser-only JavaScript when the PWA is closed.

Deploy the folder to any HTTPS static host. Open the URL in Safari, Share > Add to Home Screen.
